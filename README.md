# SHIFT (Working Title)

2D pixel-art office horror game built for GitHub Game Off 2026 (Theme: SHIFT).

## Controls
- WASD / Arrow Keys: Move
- E: Interact / Pick up clues
- Space / Left Click: Advance subtitles
